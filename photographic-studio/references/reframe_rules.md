# 构图优化重构（v0.2.0）

用户要求依据原片优化重构构图，与 G 的摄影表现力一起打造最佳成片。**每张照片都要主动判断**，能明显变好就做。本 Skill 用**确定性工具**做重构（放在 G 和细节贴回之后，保证贴回能与原片对齐）：对像素做确定性变换，不生成任何原片没有的内容。

## 1. 允许与禁止

允许：
- 裁剪、重新取景（同比例或改比例，例如 3:4 改 4:5、1:1、16:9）。
- 拉直倾斜的地平线、竖线（旋转，自动去掉空白角）。
- 透视矫正（建筑的竖线汇聚或发散明显时）。
- 用裁剪去掉边缘的干扰物（如被一侧黑墙占去过多画面）。

禁止（本版范围外）：
- 扩展画布、补全角落、内容感知填充。
- 移动、删除、增加物体或改变视角。
- 通过 G 的提示词让模型"重新构图"。
- 用裁剪掩盖 G 的失败（场景对应 STOP 的输出不能靠裁剪转为交付）。

## 2. 默认值与限制（均为**临时值**，没有证据基础）

- 画幅比例可以改，只要构图因此更好（v0.2.0，不需要用户另行要求）；`reframe.py` 用 `--box ... --allow-aspect-change`。
- 保留面积低于 0.70 时标记（v0.2.0：不禁止，人眼看画质和视野是否可接受）。
- 旋转 ≤ 5°；更大的倾斜先确认是不是照片本来就是斜的（如坡道、斜屋顶）。
- 不裁断可读文字、标志、人物或主体的关键部分。

## 3. 怎么判断"变好"

先在读原片阶段写下一句判断，再决定是否重构：
- 主体是否居中过死、或被边缘截断？
- 一侧是否有大块无信息区域（如黑墙、虚的前景）？
- 地平线或建筑竖线是否明显倾斜？
- 裁剪后主体是否更突出、画面更平衡？
**没有明显改善价值就不重构**，保持原构图。一张图只做一个方案，不给多选，避免无谓轮次；成片交付时保留未重构版本以便用户回退。

## 4. 步骤

1. 在 G 的生成与生成后检查全部完成之后进行。
2. 写一行意图：做什么、参数、理由。
3. 运行 `optional/reframe.py`（顺序：透视 → 旋转 → 裁剪），保存无损 PNG 和同名 `.json` 日志。
4. 见 `references/g_post_check.md` 第 4b 节做检查。
5. 交付时报告参数、保留面积和分辨率变化，保留未重构的 G 输出以便回退。

## 5. 为什么放在 G 之后

- G 依赖"最近一条用户消息里的原片"作为来源条件（已有的实测条件）。沙盒里生成的重构图无法同样放进用户消息，**把它当 G 的参考没有被验证过**。
- 先 G 后重构，G 的生成后检查（场景对应、框架漂移）仍然对着原片，不受影响。
- 几何重构本身是确定性的，可被日志复现和核对。

## 6. 证据与局限

- `reframe.py` 与 `check_g_output.py` 的框架漂移报告已在自测中验证：旋转后无空白角，透视往返误差小，缩放/旋转报告与参数一致。
- **尚未在真实修图任务上走过完整流程**；"哪种取景更好"是主观判断，最终由用户决定。
- 所有数字限制都是临时值。
