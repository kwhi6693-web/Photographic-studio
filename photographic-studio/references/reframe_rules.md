# 构图重构（v1.0.9）

目的（用户 2026-11-14）：**把照片呈现到最好**。只在原片的基础上做：**允许裁切，不允许扩展**。本 Skill 用确定性工具 `optional/reframe.py` 做重构（放在 G 和细节贴回之后，保证贴回能与原片对齐），不生成任何原片没有的内容。

## 1. 允许与禁止

允许：
- 裁切和重新取景，任何常用比例都可以：1:1、4:5、3:4、2:3、16:9，或保持原比例。比例按主体和画面的形状选，不需要用户另外要求（`--box ... --allow-aspect-change`）。
- 拉直倾斜的地平线、竖线（`--rotate`，自动去掉空白角）。
- 透视矫正（建筑竖线汇聚或发散明显、又不是故意的仰拍效果时，`--persp`）。

禁止：
- 扩展画布、补全角落、内容感知填充；`reframe.py` 的裁切框超出画面会直接报错。
- 移动、删除、增加物体，或改变视角。
- 通过 G 的提示词让模型“重新构图”。
- 用裁切掩盖 G 的失败（场景对应 STOP 的输出不能靠裁切转为交付）。

## 2. 怎么判断：按这张照片的看点，用审美去裁（每张都要做，结论可以是“不动”）

裁切不是套用某一种固定裁法（例如“总是只留上半部、总是改方形”），也不只为“讲故事”服务，而是**发挥审美，让这张照片的看点更好地呈现**。每张照片的答案都不一样。

### 2a. 选法：挑一两种手法，各出一个方案，选出最好的那个

1. 回到导演单第一行的**看点｜风格**（`story_style.md`），问：画面里哪些东西在成就看点，哪些在打断它？
2. 从 2c 的手法里**挑最适合这张照片的一到两种**，不要全用。手法越多，越像教科书。
3. 每种手法做**一个**裁切方案（最多两个），都用 `reframe.py` 出图。
4. 把方案和原构图放在一起看，**选出最好的一个**：哪一张最能呈现看点、画面最干净、最耐看。写明它为什么比另一个方案和原构图都好。
5. 两个方案都不如原构图 → 不动，写明理由（例如“框景本身就是看点”）。两个方案差不多 → 选改动更小的那个。

写下一行记录：**看点 → 候选手法（一到两种）→ 选中的方案和参数 → 为什么它最好**。不写理由的“保持”不算判断。

### 2b. 每次裁切都必查（不算“手法”，选中的方案都要过一遍）

- **边缘**：不在关节、门窗或柱子的中段、物体边缘上下刀；线条不要刚好擦着画框（要么留出空隙，要么明确切进去）；清掉边角的亮斑、半截杂物和抢眼的碎片。
- **地平线**：天空是看点放在下三分之一，地面或水面是看点放在上三分之一；避免正好在中间（对称倒影除外）；必须水平，除非倾斜就是表达。
- **主体完整**：主体的关键部分、可读的文字和标志、人物，要么完整保留，要么整体裁掉，不留半截。

### 2c. 手法（按看点挑选）

| 手法 | 做法 | 常用于 |
|---|---|---|
| 收紧到核心 | 裁掉稀释看点的杂乱前景、半截招牌和人群、发黑的空白 | 各种看点 |
| 保留环境 | 主体离不开环境时少裁：街道纵深、人在建筑里的尺度 | 叙事、空间与尺度 |
| 框中框 | 门、窗、树枝、拱桥形成内框，裁切让内框完整、主体落在框里 | 叙事、几何、园林 |
| 对称与中心 | 对称轴落在中线，有仪式感的主体居中，方形往往有力 | 几何与秩序 |
| 三分与黄金分割 | 主体或重要线条落在三分线或黄金分割点上，有方向的主体前方留出空间 | 各种看点 |
| 引导线 | 屋檐、街道、栏杆、河岸从边角进入、指向主体，不在半路截断 | 空间、几何、叙事 |
| 对角线与曲线 | 用斜线、三角形、S 形曲线带出动感，裁切让它们完整、走向清楚 | 几何、风光 |
| 重复与打破 | 重复元素保留完整的节奏；有一个打破节奏的元素时，把它放在关键位置 | 几何与秩序 |
| 前中后景层次 | 保留有前景的层次，画面才有纵深 | 空间、风光、园林 |
| 视觉平衡 | 大块暗面、亮色、主体都有“重量”，让两边平衡，或有意制造张力 | 各种看点 |
| 图形与背景分离 | 主体和背景的明暗或颜色要分得开，裁掉与主体混在一起的背景 | 质感、极简、光影 |
| 尺度对比 | 保留能显示大小的参照物（山前的亭、人在长廊里） | 空间与尺度 |
| 把框落在光上 | 光斑、明暗交界、剪影成为画面的结构，周围的暗留够 | 光影 |
| 按色块取景 | 主色块占合适的面积，裁掉抢戏的杂色 | 色彩 |
| 贴近材质 | 收紧到纹理最好的部分，但不裁到看不出它是什么 | 质感与细节 |
| 留白 | 天空、水面、墙面的空处给主体呼吸，主体放在留白的一侧，留白要平整 | 极简、氛围 |
| 选比例 | 高耸、纵深用竖幅；横向展开用横幅；集中、对称用方形。比例跟着看点走 | 各种看点 |
| 拉直、透视矫正 | 竖线或地平线歪了 0.5° 以上就拉直；建筑竖线汇聚明显、又不是故意仰拍时做透视矫正 | 建筑、风光 |

### 2d. 裁切做不到的

换拍摄角度、改变景深或虚化、移动或删除物体，这些只能在拍摄时决定。不要用裁切去追这些效果，也不交给 G。

参考例子（只用来说明思路，**不是模板**）：钟楼骑楼街，原片下半部是发暗杂乱的街面，上半部是阳光下的钟楼和延伸的立面。看点是钟楼和立面线条（几何与秩序加光影）。候选手法：收紧到核心（只留上部、改方形），引导线（保留原比例、只裁去最暗的底部）。前者让立面线条直接把视线引向钟楼、画面更干净，选它。如果看点是“人群中的老街”（叙事），同样的街面就应该留下。

## 3. 限制（来自照片本身，不来自偏好）

- **不扩展**：只能在原片范围内取景。
- **清晰度**：成片短边不少于 900 像素（宿主上传的原片长边约 1536），否则放大看会发软；`reframe.py` 会给出警告，主体允许时少裁一点。
- 旋转一般不超过 5°；更大的倾斜先确认是不是照片本来就是斜的（坡道、斜屋顶、故意的倾斜构图）。
- 方案最多两个，由 agent 自己选出最好的一个交付，不让用户挑；未重构的版本保留在回执里，用户可以要回原构图。

## 4. 步骤

1. 在 G 的生成与生成后检查全部完成之后进行。
2. 按第 2a 节挑一两种手法，每种用 `optional/reframe.py` 出一个方案（顺序：透视 → 旋转 → 裁切，保存无损 PNG 和同名 `.json` 日志）。
3. 按第 2b 节检查，和原构图并排比较，选出最好的一个，写下一行记录。
   选定后按 `director_brief.md` 第 4b 节写构图核对（✓／△／✗），不过就换方案或退回原构图。
4. 按 `references/g_post_check.md` 第 4b 节检查；重构后再跑一次 `physics_check.py` 和 `intensity_check.py`。
5. 交付时在回执里记下参数、保留面积、输出尺寸。

## 5. 为什么放在 G 之后

- G 依赖“最近一条用户消息里的原片”作为来源条件；沙盒里裁过的图无法同样放进用户消息，把它当 G 的参考没有被验证过。
- 先 G 后重构，G 的生成后检查（场景对应、框架漂移）仍然对着原片，不受影响。
- 几何重构本身是确定性的，可被日志复现和核对。

## 6. 证据与局限

- `reframe.py` 在自测中验证过：旋转后无空白角，透视往返误差小，裁切框超出画面会被拒绝。
- v1.0.8 之前的真实运行里，构图判断几乎都是“保持”（6 张全部保持），因为旧规则同时写了“主动判断”和“拿不准就不裁”、并限制保留面积不低于 0.80。v1.0.9 去掉了这两处矛盾；新规则还没有在真实修图里验证。
- “哪种取景更好”终究是主观判断，用户有最终决定权。
