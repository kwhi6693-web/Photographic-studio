# 反例（v1.1.0）

口味样本示范“该做到什么样”，这里示范“不能做成什么样”。写完导演单、拿到成片时各对照一次：落进任何一种，就改导演单或改路线，不交付。

## 1. 有图的反例（`assets/counter/`，左原片、右被否定的结果）

| 反例 | 错在哪 | 怎么避免 |
|---|---|---|
| `c01_unchanged_garden_before_bad.jpg` 逆光园林 | 改了等于没改：成片与原片平均色差只有 2.0。用户看过对比，认为 G 路线“更能突显照片的表现力”（G 路线见样本 13） | 验收时先问“看得出改了吗”；看不出就补调，不能交付 |
| `c02_unchanged_screen_window_before_bad.jpg` 屏风窄窗 | 同上，平均色差 3.3，暗室没有提亮（对比样本 15） | 同上 |
| `c03_unchanged_lake_before_bad.jpg` 枝叶框景的湖 | 同上，平均色差 2.6，天空和湖面仍是灰的（对比样本 16） | 同上 |
| `c04_invented_painting_before_bad.jpg` 透光屏风（局部） | G 在屏风上重画了原片没有的牡丹，它的颜色被带进成片，左侧屏面出现一块块暖色斑 | G 改了画面内容（画作、文字、图案）就作废这一版；斑块状的色彩变化不能交付 |
| `c05_removed_light_beam_before_bad.jpg` 蓝釉瓶 | G 把左上方墙上那道真实的光束压没了（删光） | 原片里真实的光束、光斑、反光都要保住；对照原片逐一找光 |

1–3 来自 2026-11-13 第一批（v1.0.1 退回 N 直出）；4–5 是 2026-11-13 第二批被检查正确拦下的 G 路线。

## 2. 只有文字的反例（用户以前否定过，原图不在包里）

- **AI 味**（2026-11-11 石桥游船，v0.3.1）：“有些地方过于平滑显得成片整体 AI 味较高”。树叶、石材被磨平。→ 成片的纹理必须来自原片。
- **假光圈**（2026-11-11 博物馆展品，v0.3.6）：展品周围出现明显的光圈和亮雾。→ 暗背景保持原片的暗和干净（`physics.md`）。
- **过度**（2026-11-11 中山陵祭堂）：同一张原片两次运行强度差约一倍，用户选克制的一张，“会自然些”。→ 按 `intensity.md` 的范围，不追求“越强越好”。
- **太弱**（2026-11-11 蓝釉瓶、青瓷罐，v0.3.7）：“肉眼看不出与原片的区别”。→ 博物馆题材按第 3 档做出看得见的提升。
- **场景不符**（2026-11-09 金色花雕）：G 的结构和亮度与原片对不上（结构相关 0.759，L* +13）。→ `check_g_output.py` 报场景不符就作废。
- **改了文字或人物**（2026-11-10 街景路牌、威尼斯运河）：G 重画了路牌文字和行人。→ 关键细节贴回原片（`detail_restore.md`）。

## 3. 记录新反例

用户说“不要这样”，或明确否定一张成片时：在本对话里记一行 `照片类型｜错在哪｜用户原话｜下次怎么避免`；用户同意时，把原片和那张成片做成左右对比图加进 `assets/counter/`（仓库维护者合入）。
