# G 成片的生成后检查（v0.1.5）

> **v1.0 中的位置**：G 调用后先用 `optional/check_g_output.py` 做本文件的检查。不通过（类型错误、场景对不上）时**这一版作废**，改提示词重试或走 N 直出（见 `principles.md` 第 4 节），不是停下不交付。默认路线的成片不含 G 的像素，所以本文件里关于文字、纹理被重绘的条目只在升级路线（G + 细节贴回）里需要。


目的：在交给用户前，拦住"比例漂移、场景不对应、类型错误"这类明显失败，并如实报告强度与细节风险。**这些检查不能证明文字、标志、纹理保真**。v0.1.5 起通过标准是“整图正常观看下与原片高度近似”：场景对应检查通过即可继续，纹理级差异只披露、不拦截。

## 1. 必做检查（有无脚本都要做）

| 检查 | 方法 | 不通过时 |
|---|---|---|
| 类型 | 输出是照片，不是海报/文档/拼图 | STOP |
| 比例 | 输出宽高比与原片之差 ≤ 0.02 | v0.2.0 起只标记（`ASPECT_CHANGED`），人眼确认没有裁掉或拉伸重要内容 |
| 场景对应 | 并排看：构图、主体位置、透视一致；有脚本时用下表 | STOP |
| 框架漂移 | 脚本报告整体缩放、旋转、中心位移；G 不应改变构图 | 报告 `framing_warning`，并按场景对应一并判断 |
| 新增削波 | 全白/全黑像素比例不应明显高于原片 | 报告并交用户判断 |

## 2. 可选脚本 `optional/check_g_output.py`

用法：`python3 -I check_g_output.py 原片 输出`，输出 JSON。需要 Python、Pillow、numpy、OpenCV（v0.3.5 起不需要 scikit-image）。

- `aspect_ok`：比例检查（|差| ≤ 0.02）。
- `structure_corr`、`orb_inliers`：场景对应。当前**临时**判据 ≥0.8 且 ≥300，在 5 张样本上定下，**没有留出集验证**，不要当作可靠阈值。
- `framing_scale`、`framing_rotation_deg`、`framing_center_shift_x/y`：G 输出相对原片的整体缩放、旋转和中心位移，用来发现**同比例的缩放或平移**（比例检查拦不住）。5 张实测输出都在缩放 0.997–1.005、旋转 ≤0.25°、位移 0.000；`framing_warning` 的阈值（缩放 0.97–1.03、旋转 1°、位移 0.02）是据此设的**临时值**，只报告，不是及格线。
- `L_star_mean_change`、`chroma_ratio`：强度，**只报告，不拦截**。
- 不检查文字、标志、纹理是否被重画。
- v0.1.5：判定为 STOP 时脚本以退出码 2 结束（此前 STOP 也返回 0）；仍应以 JSON 里的 `verdict` 为准。
- 没有环境或脚本时，用人工并排对照做同样的判断，并写明"未跑脚本"。

## 3. 强度参考（描述性，不是及格线）

历史认可的 4 张样片：L* 均值变化约 +2.7 到 +7.8，色度约 ×1.38–1.83，局部对比约 ×1.14，深暗部保留。WO-3 的 C 照片 L* +9.04 略超上限，用户仍接受。超出范围时报告数值并让用户判断，不自动重做。

## 4. 执行者复核（v0.1.5：只查文字、人物、整体结构）

由执行者完成，**不交给用户逐项比对**。画面里有下列内容时才需要在 100% 看；没有就跳过并写明“无文字/人物”。

- 关键细节（文字与符号、人物、动物、车船、艺术品、可数小构件）被改动：先按 `detail_restore.md` 贴回原片像素；超过面积上限、对不齐或贴回后有可见接缝时 STOP。
- v0.2.0：以人眼正常观看为准。G 改了构图或视角、改了结构、增删了物体，只要人眼能看出且贴回不了（对不齐或接缝可见）才 STOP；贴得回就贴回；人眼看不出就不处理。见 `principles.md`。
- 只披露、不拦截：木、石、灰泥、瓦等材质纹理，云形，水面与倒影，树叶被重新渲染。回执里写一句“以下内容为重新渲染：……”。
- 依据：用户 2026-11-10 看过 WO-10 的 1:1 局部后表示可以接受，并确定“与原片高度近似即可”。

此前各版的实测记录保留如下，供执行者参考：
- 所有可读文字、招牌、标志：逐字比对，列出任何字形变化（实测：A 的标志圆盘字形被改过）。
- 人物：位置、衣着、数量。
- 石材、砖、木面：是否凭空出现雕刻或颗粒（实测：B 的石墙被加了雕刻感纹理，用户仍接受）。
- 水滴、树叶、远处小字：多半是重新合成的，不要说"保真"。

## 4b. 几何重构后的检查

几何重构发生在 G 检查**之后**，对象是 G 输出。重构后另做：
- 核对 `reframe.py` 生成的 JSON：来源和输出的 SHA256、参数、保留面积、警告。
- 用脚本比较「G 输出 vs 重构后成片」应看到与参数一致的缩放/旋转/位移（实测：zoom 1.15 报告 1.149，旋转 2° 报告 −2.03°）。结构相关此时会大幅下降，这是预期，**不要用它判断重构后的成片**。
- 1:1 复核仍对重构后的成片做一次，重点看裁切边缘、被裁入或裁出的文字/标志。

## 5. 报告用语

- 可以说：整图观看下与原片高度近似；场景、构图、主体与原片对应；列出的内容为重新渲染。
- 不可说：零重绘、逐像素保真、纹理保真、保留了全部真实细节、"检查脚本通过所以文字没问题"。
- 摄影是否接受由用户决定。
