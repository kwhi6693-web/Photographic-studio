# 风格库（v1.1.0）

**命名风格**和**参考图用法**，只在用户说“风格：xx”“参考这张”或“多出几版”时用；默认的“修”不读这一页。

## 1. 命名风格（`assets/styles.json`，`optional/style_params.py`）

| 风格 | 一句话 | 适合 | 避开 |
|---|---|---|---|
| 自然通透 `natural_clear` | 真实的颜色、干净的白、暗部打开但仍是暗的 | 几乎所有题材 | — |
| 暖调胶片 `warm_film` | 暖的高光、略抬的黑、柔和反差、颜色略淡 | 街头、旅行、白天建筑、傍晚 | 博物馆展柜、夜空（黑会变灰） |
| 冷调纪实 `cool_documentary` | 中性偏冷、克制的颜色、结实的反差 | 城市、阴天、混凝土与钢 | 暖光室内、夕阳 |
| 暗调电影 `low_key_cinema` | 深的暗部、收住的高光、暗部微冷亮部微暖 | 博物馆展柜、夜景、单一主光的室内 | 明亮的白天 |
| 高调清新 `high_key_airy` | 明亮、柔和、暗部打开、偏冷的干净白 | 白天室内、窗边静物、白色建筑、阴天 | 暗展柜、夜景 |
| 东方雅致 `oriental_elegant` | 柔和的灰绿、红与木色的暖点、水墨和漆器般的温和反差 | 园林、寺庙、漆器、瓷器、书法、木作 | 霓虹夜街 |

用法：`python3 -I optional/style_params.py 风格 参数.json [--base=导演单参数.json]`，输出 N 的参数和一句给 G 的风格描述（写进 G 提示词的风格方向一行）。风格只决定方向；物理检查、力度检查照常把关，风格不是越过它们的理由。每种风格都在 10 张测试照片上跑过物理检查：只有“暖调胶片”用在夜景上不过（已写在“避开”）。

## 2. 用户给的参考图（“参考这张”）

用户把一张参考图和原片一起发来时：

1. 把参考图和原片一起交给 G，提示词的风格方向写“按参考图的色调和影调风格，只取风格，不取内容、构图和光源”。G 最会分辨什么是风格、什么是画面内容；它是参考风格的主要载体。
2. 运行 `optional/reference_style.py 原片 参考图 参数.json`：只取跟画面内容无关的部分（近中性像素上的色偏、暗部和亮部各自的偏色）和一小部分饱和度，默认走到六成，有上限。亮度、反差跟画面内容有关（一面亮墙、一片夜空），只写在报告里给导演判断。
3. 把这份参数并进导演单的 N 参数，照常跑 `finish.py`。
4. 参考图是别人的作品：只在本次对话里用来看风格，不保存、不放进成片、不加入口味样本。

## 3. 更新（与时俱进）

- **用户反馈**（最重要）：“记住这张”“不要这样”随时记下口味（`taste_profile.md` 第 3 节），跟的是这位用户的审美。
- **季度更新**：每季度一次，调研当季的后期风格趋势，提出 `styles.json` 和本文件的修改建议，开成 PR；用户批准才合入。合入前同样要过测试：每种风格在测试照片上跑物理检查，不能伤到用户认可过的样本。
- **原则不变**：物理合理、不造光、去 AI 味、与原片高度近似。潮流只改变风格，不改变这几条。
