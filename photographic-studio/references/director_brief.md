# 导演单（v0.3.0）

导演单是这张照片的后期方案：agent 的“大脑”把读片结果变成对 G 和 N 的具体指挥。**不超过 6 行，写给自己用，默认不给用户看**（用户说“看回执”时再给）。

## 1. 写之前

1. 运行 `optional/measure.py 原片`，得到客观数据（影调、色彩、天空、注意力位置）。数据只是佐证，**以眼睛看到的为准**。
2. 按 `story_style.md` 读出故事、情绪、主角、风格方向；按 `craft_reading.md` 看光、色、影调、引导、空间。
3. 只加载这张照片所属题材的那一页（`genres/`）。
4. 看一眼 `taste_profile.md` 里用户认可的成片，校准方向和强度；强度按 `intensity.md` 第 2 节的范围写（v0.3.6：用户偏好自然，不要过度）。**导演单写完后对照同题材的样本检查一遍幅度**（v0.3.4）：导演单若比用户认可的样本明显保守（例如夜景写“树岸仅露轮廓”“只提亮已有光照部分”），按样本的幅度改写。

## 2. 格式（六行）

```
故事｜风格：<一句故事>｜<一句风格方向>
主角：<是什么、在画面哪里>；怎么突出：<压暗周边／加反差／收敛其他颜色／放大已有的光…>（不给主角另加光）
影调：黑场 <保留纯黑／略抬>，高光 <压多少>，暗部 <提多少>，整体反差 <加／减>
色彩：主色 <…>，要加强 <…>，要收敛 <…>，冷暖 <更暖／更冷／拉开对比>
不能动：<文字、人物、标志性物体、时间与天气…>
构图：<保持／裁掉哪里／拉直／改比例>，理由 <一句>
```

每一项都要能在成片上检查：写“天空更深、有层次”，不写“更好看”。

## 3. 翻译成指挥

| 导演单 | 给 G（有 G 时） | 给 N（`grade.py` 参数） |
|---|---|---|
| 故事｜风格 | 提示词的“摄影意图”一行（`g_prompt_template.md`） | 整体方向：`contrast`、`tone_split`、`white_balance` |
| 主角怎么突出 | 写明主角和光的去向 | 优先压暗周边（`vignette`、`hues`）；`regions` 提亮只用于本来受光的主角（v0.3.7） |
| 影调 | 写大方向 | `levels`、`shadows`、`highlights`、`contrast`、`clarity` |
| 色彩 | 写主色与冷暖 | `saturation`、`vibrance`、`hues`、`tone_split` |
| 不能动 | 只在无法贴回时写保护行 | N 本身不改内容；贴回由 `text_restore.py` 负责 |
| 构图 | 不让 G 改构图 | `reframe.py` |

- **有 G 时**：G 负责大的光影和氛围，N 只补 G 没做到的部分，数值要小。
- **没有 G，或 G 的候选都不合格时**：N 直出，按导演单完整执行，数值可以更大，但仍以自然为限。
- 参数怎么选见 `craft_prescriptions.md`；每个参数的范围见 `n_grade.md`。

## 4. 验收：拿成片对照导演单（v0.3.1：必做，留记录）

时机：贴回之后、防过冲（`n_trim.py`）之前。逐行问：做到了吗？再跑一次 `measure.py`，和原片的测量对比，看数字是否朝导演单的方向走了：

- 主角：`layout.L_mean_3x3` 里主角所在格相对周围是变亮了还是变暗了；`attention.centroid_xy` 是否更靠近主角。
- 影调、色彩：整体 ΔL*、色度比（有 G 时见 `check_g_output.py`）的方向和幅度，是否符合导演单和 `taste_profile.md`（用户认可的样本：亮度小幅提高，色彩明显加强）。
- **提升必须看得见**（v0.3.4）：把成片和原片并排看，并对比两次 `measure.py`。出现下面任一情况，“主角”或“影调”不得标 ✓：主角所在格没有比原片更亮或反差更大（导演单明确要压暗的除外）；成片整体比原片更暗而导演单没有要求压暗；并排看不出明显差别。
- **回执里的标记必须处理**（v0.3.4）：`look_transfer.py` 标 `LOOK_ONLY_PARTLY_CAPTURED`（带过来的光色不到一半）时，不得直接进入交付：先确认用的是默认的 `--local=1`；再对照回执里 G 和成片各自的 L 变化、色度比，用 `grade.py` 把差的部分补上；补不上且导演单的关键效果没有达到，走升级路线。处理结果写进验收记录。

**写下验收记录**（存进回执，默认不显示；没有这份记录不得交付）：

```
验收：故事风格 ✓｜主角 △（树冠比轩榭更抢眼）｜影调 △（整体变暗 3.9，廊下没有提亮）｜色彩 ✓｜不能动 ✓（已贴回 4 处）｜构图 ✓｜自然度 △（瓦面和石基过于平滑）
决定：texture_blend 回补瓦面、石基；N 精修（提亮轩榭区域、略收黄绿）
```

**固定用这个格式和这七个项目名**（v0.3.2；第七项“自然度”按 `naturalness.md` 第 1 节检查；“影调”“色彩”两项附 `intensity_check.py` 的结论，v0.3.6）。每项只用 ✓（做到）、△（方向对但不够，或有偏差）、✗（没做到或做反了），△ 和 ✗ 后面用几个字写明差在哪。“决定”一行必须有。然后按下面的规则做决定：

- 七项都是 ✓ → 交付。
- 自然度是 △ 或 ✗ → 先按 `naturalness.md` 第 2 节修，修完重新验收，再交付。
- 主角、影调、色彩里有 △ → **必须用 N 精修至少一轮**（`grade.py`，最多 3 轮），精修后重新验收；确实补不了的，写明原因再交付。
- 方向不对，或 G 改了不该改的 → 有 G 时重跑一次 G（共最多两次）；仍不行就走保底（N 直出）。

## 5. 例子（石壁鸽群，N 直出，实测）

```
故事｜风格：傍晚林间的旧石壁，鸽子停满墙头，安静而有年代感｜肃穆古迹：石材厚重，林子透出一点暖光
主角：石壁和墙头的鸽群，画面中央；怎么突出：整体提亮石壁，四周压暗
影调：黑场略收，高光不动（鸽子的白要干净），暗部略提让树有层次，反差加
色彩：主色灰与绿，绿略加强，高光带一点暖
不能动：鸽子的数量和位置、回纹雕刻、墙面水渍
构图：保持
```

对应参数：`levels {black 2, white 88}`、`shadows 4`、`contrast 0.18`、`clarity 0.32`、`vibrance 0.2`、`hues {green sat 1.3, yellow sat 1.2}`、`tone_split {shadows [0,-2], highlights [0.5,3]}`、`regions [椭圆覆盖石壁 lift 5]`、`vignette 7`。结果：L* +4.0，色度 ×1.30，结构相关 0.989，没有新增过曝。
