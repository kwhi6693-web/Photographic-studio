# 导演单（v0.3.0；v1.0.9 逐张诊断）

导演单是这张照片的后期方案：agent 的“大脑”把读片结果变成对 G 和 N 的具体指挥。**写给自己用，默认不给用户看**（用户说“看回执”时再给）。

## 1. 写之前（v1.0.9：每张照片的参数只从这张照片来）

1. 运行 `optional/measure.py 原片`，得到客观数据（影调、色彩、天空、注意力位置）。数据只是佐证，**以眼睛看到的为准**。
2. 按 `story_style.md` 读出故事、情绪、主角、风格方向；按 `craft_reading.md` 看光、色、影调、引导、空间。
3. 只加载这张照片所属题材的那一页（`genres/`）。
4. **逐条诊断**：把 `craft_prescriptions.md` 的诊断表从上到下过一遍，只写出这张照片**确实有**的问题，每条写明依据（看到了什么＋哪个测量数字）。也要判断“这张照片哪里已经很好、不该动”（见表中“光线已经很好”一行）。
5. 参数**只能**来自第 4 步写出的诊断：每个参数后面注明它对应哪一条诊断，数值按问题的轻重在处方范围内取（问题轻取下端，重取上端）。没有诊断支持的参数不写；**不使用任何默认参数组**。
6. 同一批里有两张照片的参数完全相同 → 说明没有逐张判断，重新诊断其中后一张。

## 2. 格式

```
故事｜风格：<一句故事>｜<一句风格方向>
诊断：①<问题>（依据：<看到的>；<测量数字>）②…；不该动：<哪里已经好>
主角：<是什么、在画面哪里>；怎么突出：<压暗周边／加反差／收敛其他颜色／放大已有的光…>（不给主角另加光）
影调：黑场 <…>，高光 <…>，暗部 <…>，整体反差 <…>（每项注明对应诊断，或写“不动”）
色彩：主色 <…>，要加强 <…>，要收敛 <…>，冷暖 <…>（同上）
不能动：<文字、人物、标志性物体、时间与天气…>
构图：<保持／裁掉哪里、改成什么比例／拉直几度>，理由 <一句>（按 `reframe_rules.md` 第 2 节四问）
参数：{grade.py 参数}，逐个注明 ①②…
```

每一项都要能在成片上检查：写“水面去雾、黑场落到窗框以外的景物上”，不写“更好看”。

## 3. 翻译成指挥

| 导演单 | 给 G（有 G 时） | 给 N（`grade.py` 参数） |
|---|---|---|
| 故事｜风格 | 提示词的“摄影意图”一行（`g_prompt_template.md`） | 整体方向：`contrast`、`tone_split`、`white_balance` |
| 主角怎么突出 | 写明主角和光的去向 | 优先压暗周边（`vignette`、`hues`）；`regions` 提亮只用于本来受光的主角（v0.3.7） |
| 影调 | 写大方向 | `levels`、`shadows`、`highlights`、`contrast`、`clarity` |
| 色彩 | 写主色与冷暖 | `saturation`、`vibrance`、`hues`、`tone_split` |
| 不能动 | 只在无法贴回时写保护行 | N 本身不改内容；贴回由 `text_restore.py` 负责 |
| 构图 | 不让 G 改构图 | `reframe.py` |

- **有 G 时**：G 负责大的光影和氛围，N 只补 G 没做到的部分，数值要小。
- **没有 G，或 G 的候选都不合格时**：N 直出，按导演单完整执行，数值可以更大，但仍以自然为限。
- 参数怎么选见 `craft_prescriptions.md`；每个参数的范围见 `n_grade.md`。

## 4. 验收：逐条核对诊断（v1.0.9，必做，留记录）

时机：贴回之后、防过冲（`n_trim.py`）之前。把成片和原片并排看，并再跑一次 `measure.py` 对比。**按第 1 步写出的诊断逐条核对**，不打笼统的总评：

```
验收：①水面发雾 ✗（水面仍发白，黑场只落在窗框上）②左侧漏光 ✓ ③…｜不该动的地方：✓ 天空未变｜自然度 ✓｜物理 ✓
决定：①补一轮：levels.black +3，水面 regions lift −3
```

- 每条诊断只能是 ✓（修好了）、△（方向对但不够）、✗（没修好或做反了），后面写看到的事实。**不能用“IN_RANGE”代替眼睛的判断**；测量数字只作佐证。
- “不该动”的地方被动了（例如光线本来很好的照片被提亮）记 ✗。
- 自然度按 `naturalness.md` 第 1 节；物理看 `physics_check.py`。
- 有 △ 或 ✗ → 用 `grade.py` 针对那一条补一轮（最多两轮），补完重新逐条核对；补不了的写明原因再交付。
- 方向不对，或 G 改了不该改的 → 有 G 时重跑一次 G（共最多两次）；仍不行就走保底（N 直出）。
- 回执里 `look_transfer.py` 的 `LOOK_ONLY_PARTLY_CAPTURED` 标记：确认用的是默认 `--local=1`，差的部分按诊断用 `grade.py` 补上。

## 5. 例子（石壁鸽群，N 直出，实测）

```
故事｜风格：傍晚林间的旧石壁，鸽子停满墙头，安静而有年代感｜肃穆古迹：石材厚重，林子透出一点暖光
主角：石壁和墙头的鸽群，画面中央；怎么突出：整体提亮石壁，四周压暗
影调：黑场略收，高光不动（鸽子的白要干净），暗部略提让树有层次，反差加
色彩：主色灰与绿，绿略加强，高光带一点暖
不能动：鸽子的数量和位置、回纹雕刻、墙面水渍
构图：保持
```

对应参数：`levels {black 2, white 88}`、`shadows 4`、`contrast 0.18`、`clarity 0.32`、`vibrance 0.2`、`hues {green sat 1.3, yellow sat 1.2}`、`tone_split {shadows [0,-2], highlights [0.5,3]}`、`regions [椭圆覆盖石壁 lift 5]`、`vignette 7`。结果：L* +4.0，色度 ×1.30，结构相关 0.989，没有新增过曝。
