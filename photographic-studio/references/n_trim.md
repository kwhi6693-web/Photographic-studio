# G 后 N 收束（v0.1.5）

> **v1.0 中的位置**：`n_trim.py` 只作为交付前最后一步，检查高光削波过冲（任一通道=255 的像素 > 0.1%）；没有过冲就 `SKIP`，什么都不做。下文关于“G→N 链路”“交付 G 并标为‘G’”的说法是 v0.1.x 时期的，现在的路线和标签以 `SKILL.md` 和 `delivery.md` 为准。


用户 2026-11-10 决定：本项目默认生成链路为 **G→N**。本文件规定 N 这一步怎么做、怎么检查、失败怎么办。**这是链路选择，不是实验结论**：没有证据显示 G→N 优于 G 单步。

## 1. 定位

- N 是 G 之后的**收束**：收紧色彩过冲和高光，保住 G 已建立的观感。**不是改色**。
- **v0.1.5 触发条件**：只在 G 输出存在高光削波过冲时执行，即任一通道=255 的像素比例 > 0.1%（与第 3 节“过曝”上限同一数值）。不超过时 `optional/n_trim.py` 不写输出文件，返回 `SKIP`，交付 G 并标为“G”。用户明确要求把颜色收一收时，可加 `--force` 强制执行。
- 依据：四张实测里 N 的改动 99% 的像素不超过 5–8 级（0–255），用户认可的三张展示图都更接近 G；只有建筑一张的削波（0.41%）超过上限。暖色过饱和目前没有批准过的数值判据，不作为自动触发条件。
- 不改变构图、结构、纹理；不锐化；不加颗粒；不缩放；不裁切。
- 顺序：G → 生成后检查（`g_post_check.md`）→（如做）几何重构 → N。N 的输入就是本来要交付的那张图。
- 与"N 独立保真路线"（`SKILL.md` 路线优先级）是两回事：本文件只管 G 后收束。

## 2. 默认预设（**单次测试值，未验证**）

来源：WO-7 在水面照片 R1 上的一次实测（Python 3.13、Pillow、NumPy、scikit-image、OpenCV，确定性 Lab 调色）。

| 参数 | 数值 |
|---|---|
| 暖金区域色度最大降低 | 12% |
| 暖色识别 b* 起点 / 过渡宽度 | 6 / 12 |
| 暖色识别 a* 起点 / 过渡宽度 | −6 / 12 |
| 高光调整 L* 起点 / 过渡宽度 | 60 / 25 |
| 最大 L* 压低幅度 | 1.8 |
| RGB 高光软压缩起点 / 斜率 | 0.965 / 0.50 |
| 锐化、颗粒、缩放、裁切 | 0 / 0 / 否 / 否 |

实测效果（R1）：平均 ΔL* −0.14，色度比 ×0.95，任一通道=255 的像素 0.48% → 0%，结构相关 0.9999。**观感几乎不变，它是"防过冲收口"**。用户 2026-11-10 确认 N 的强度定为“防过冲收口”。要加大强度，须用户另行决定，并改预设、按第 3 节重新验证。

## 3. 必做检查

| 检查 | 要求 | 不通过时 |
|---|---|---|
| 工具 | 确定性代码或明确参数；**无任何生成式调用** | 视为 N 未执行 |
| 记录 | 每个参数的具体数值、代码或脚本、环境版本；没有记录视为未执行 | 视为 N 未执行 |
| 亮度 | 平均 \|ΔL*\| ≤ 3（相对 N 前） | N 失败 |
| 色度 | 色度比在 0.80–1.00（N 只收不加） | N 失败 |
| 过曝 | 任一通道=255 的像素比例 ≤ 0.1%，且不高于 N 前 | N 失败 |
| 结构 | N 前后结构相关 ≥ 0.98 | N 失败 |
| 禁止项 | 无锐化、颗粒、缩放、裁切 | N 失败 |

幅度上限和结构阈值是**初始值**，依据只有一次水面测试，没有留出集验证。`optional/n_trim.py` 输出这些数值和 `PASS`/`FAIL` 判定；没有脚本时按上表人工核对并写明"未跑脚本"。

## 4. 失败、未执行与无调整

- **环境无法运行代码**：跳过 N，回执写"N 未执行：环境无法做确定性调色"。**不得用生成式工具代替**。
- **N 失败**：交付 N 之前的图，标为"G"，并报告哪一项未通过。
- **无过冲（v0.1.5）**：脚本返回 `SKIP`，不产生 N 文件，标为"G"。这是正常结果，不是失败。
- **N 对这张图没有改善**：允许 N = identity（无调整），必须写明原因，标为"G"。
- 只有 N **实际执行且通过**，才能标"G→N"。

## 5. 回执字段

N 前、N 后文件的 SHA256 和分辨率；工具、代码或脚本、环境版本；每个参数的数值；第 3 节各项实测值；判定。字节级结果不保证跨环境一致（浮点取整），哈希用于标识具体文件，**不是复现证明**。

## 6. 已知限制

- 只在一张水面照片上测试过（R1）；其他场景（建筑、室内、灰调、人造光）未验证。
- 预设强度很轻，对观感的影响接近不可见；它的实际价值主要是防过冲。
- 不检查文字、标志、纹理是否被重画（N 不应改变它们，但 G 已经可能改过，见 `g_post_check.md` 第 4 节）。
