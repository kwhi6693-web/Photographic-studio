# 总则（v1.0）

本文件汇总用户在 2026-11-09 至 11-11 定下的原则。其他参考文件的数字和清单都服从这里。

## 1. 目标

用户上传原片，直接得到这个 agent 能做出的最好一张成片：

- **表现力第一**：主体更突出，光影、色彩、空间更有层次，看得出明显提升。“改了等于没改”算失败。
- **高度像原片**：同一场景、同一时刻、同一视角。以整图正常观看为准，不要求像素一致。
- **符合自然光的物理规律**：放大照片里本来就有的光，不画一种现实中不会出现的光（`physics.md`）。
- **看不出 AI 痕迹**：没有磨平、塑料感、假细节、假 HDR（`naturalness.md`）。
- **看点和风格**：提升的方向由这张照片自己的看点（叙事、几何、光影、色彩、质感、氛围……）和风格决定（`story_style.md`，v1.0.9），不套固定滤镜、固定暖金色或高饱和。

## 2. 三条原则（用户 2026-11-10）

1. **人眼看不出即可。** 看不出差异就算一致，看不出接缝就算合格；200% 放大只用来确认已发现的问题。
2. **构图可以重构，把照片呈现到最好。** 只在原片基础上做：允许裁切（任何常用比例）、拉直、透视矫正，不允许扩展画面；在 G 之后做，不由 G 完成（`reframe_rules.md`）。
3. **贴回范围放宽。** 升级路线里，任何被 G 改动、人眼能看出的对象，只要能对齐、贴回后看不出接缝，都可以贴回（`detail_restore.md`）。

## 3. 路线

- **默认：原片像素 + G 光色 → N 精修**（用户 2026-11-11 比较后选定）。成片的纹理、文字、人物全部来自原片；G 只提供光线和色彩。由 `optional/finish.py` 一步完成，含自动重做阶梯。
- **N 直出**：没有 G、G 的候选都不合格、或用户要求非生成式时。必须标为 `N 直出`。
- **升级：G + 细节贴回**：只在默认路线缺的正是 G 像素才有的效果时使用，且必须通过自然度检查。
- G 最多调用两次。G 的提示词以表现力为目标，不写“克制、只做色调”这类压低强度的词，也不写数字目标。

## 4. 作废与保底

下面的情况发生时，**这一版作废**，自动换下一级或改走 N 直出，不空手而归：

| 情况 | 原因 |
|---|---|
| G 的输出与原片场景对不上（`check_g_output.py` 不过） | 成片不是这张照片 |
| 物理检查不过（假光圈、暗斑、明暗反转、光晕等） | 违反自然光的规律 |
| 超出力度上限，或看不出变化（`intensity_check.py`、`finish.py`；v1.0.9 起低于下限不算） | 太强不自然；改了等于没改算失败；轻重由这张照片的诊断决定 |
| 校准的总结论是 `DO_NOT_DELIVER` | 表现力被削掉了 |
| 升级路线里关键事实的改动贴不回 | 交付就会带着可见的错误 |

**拿不到成片的情况只有**：主体是人像；原片读不了；宿主既无 G 也不能运行代码；用户只要分析。

**永远禁止**：改动或替代本包的工具；把 N 的结果标成 G；声称做了没做的检查。

## 5. 标记（照常交付，回执列出）

工具产生的标记（例如 `G_GLOW_NOT_CARRIED`、`G_LIGHT_REMOVAL_NOT_CARRIED`、`G_SHARPER_THAN_SOURCE`、`LOOK_ONLY_PARTLY_CAPTURED`）、画幅比例变化、裁切后成片短边低于 900 像素、拉直超过 5°（`reframe.py` 警告；v1.0.9 起不再限制保留面积）、贴回面积大、执行者拿不准的情况。标记不阻止交付，写进回执和累计标记表（`flag_log_template.md`），攒够一批后统一调整规则，**中间不逐张改规则**。

## 6. 如实

- 默认路线的成片纹理来自原片，可以说“纹理、文字、人物来自原片”；升级路线的成片含有 G 重新渲染的内容，必须说明。
- 不说“零重绘”“完全保真”“已稳定达标”；用户满意的一张不代表所有场景都能稳定复制。
- 不能保证复现历史上某次生成的结果：本 Skill 复现的是决策方法、约束和检查，不是隐藏的提示词、种子或模型。
- 成片是否满意由用户决定；未经用户认可不标记为通过。
