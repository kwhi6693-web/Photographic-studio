# 强度：每次都落在用户喜欢的范围里（v0.3.6）

## 1. 为什么要有这一条

2026-11-11，同一张原片（中山陵祭堂立面）、同一套规则（v0.3.4 与 v0.3.5 在影响效果的部分完全相同）跑了两次，强度差了约一倍：

| | 整体提亮 | 色彩浓度 | 受光面变暖 | 最亮处 | 天空 |
|---|---|---|---|---|---|
| 第一次（用户选这张：“会自然些”） | +3.8 | ×1.14 | −1.2 | −1.3 | +2.3 |
| 第二次 | +4.1 | ×1.35 | +5.2 | +6.9 | −4.3 |

原因：导演单的“加多少”由执行者每次自己决定。本文件把用户的偏好写成数字范围，由脚本检查，超出就校准。

**两条同时成立（用户 2026-11-11）**：
1. 偏好自然，不要过度。
2. **表现力不能受影响。** 所以范围的**下限是表现力底线**（必须达到，达不到就加强）；上限只用来去掉“过”的那一部分，**不是把成片往中间拉**。

## 2. 范围（来自用户认可的成片）

`optional/intensity_check.py 原片 成片` 按原片自动分三类（也可用 `--genre=` 指定）：

| 类别 | 整体提亮 ΔL* | 色彩浓度比 | 受光面变暖 Δb | 最亮处 p99 变化 | 天空 ΔL* | 局部反差（成片 ÷ 原片） |
|---|---|---|---|---|---|---|
| day（日光、色彩正常） | +1 … +5 | ×1.08 … ×1.30 | ≤ +4 | ≤ +3 | −4 … +3 | ≥ 1.0 |
| lowcolour（原片色彩很淡：阴天、灰调） | +1 … +5 | ×1.20 … ×2.80 | ≤ +5 | ≤ +3 | −6 … +3 | ≥ 1.0 |
| night（夜景、弱光） | +0.5 … +4 | 不限 | ≤ +6 | 不限 | ≤ +1.5 | ≥ 1.0 |

下限（整体提亮、色彩浓度、局部反差）是表现力底线：成片不得比原片更平、更淡、更暗。用户认可的样本局部反差为原片的 1.12–1.42 倍。

依据：用户认可的成片全部在范围内（祭堂第一次；WO-8 建筑、运河、夜景三张“很满意”；夜景 v0.3.4 重跑）。用户没选的祭堂第二次有四项超出；v0.3.3 那张过弱的夜景整体提亮不足。

## 2b. 博物馆、展柜、低调静物（`--genre=museum`）

这类照片大片是暗背景，全图平均数看不出主角有没有变好，所以**按主角判断**（用户 2026-11-11 在 5 档力度对比里选定第 3 档）：

| 项目 | 范围 |
|---|---|
| 主角颜色（色度比） | 1.30 – 1.85 |
| 主角局部反差 | ≥ 1.14 倍 |
| 主角提亮 | ≤ 7 L* |
| 暗背景提亮 | ≤ 3 L* |

参数起点和注意事项见 `genres/still_life.md`。用 `intensity_check.py 原片 成片 --genre=museum`；`finish.py --genre=museum` 力度不够时会自动加到这一档。

## 3. 怎么用（验收时必做）

1. 精修后、交付前，运行 `intensity_check.py 原片 成片`。
2. `IN_RANGE` → 继续验收其他项。
3. `OUT_OF_RANGE`：
   - **低于下限**（太弱）→ 按 `fix` 提示加强（例如 `vibrance`、`clarity`、`contrast`；不用给主角加一圈亮来凑数，v0.3.7），这是表现力底线，必须补上。
   - **高于上限**（过度）→ **只去掉超出的部分**：只调超出的那几项，**只调到刚好低于上限**；不动没超出的项目；不用全局 `saturation` 压色（改用只针对过头颜色的 `hues`）；压高光会让局部反差下降时，同时加一点 `clarity` 补回。
   - v0.3.8：总结论是 `DO_NOT_DELIVER` 时不得交付，必须撤回这一轮。
   - 校准后用 `intensity_check.py 原片 校准后 --before=校准前` 再检查。回执的 `calibration.verdict` 必须是 `EXPRESSIVENESS_KEPT`（局部反差保留 ≥ 97%、主角没有明显变暗、没超出的颜色没被削弱、超出的颜色没被削过头）；是 `EXPRESSIVENESS_LOST` 就撤回这一轮，按提示重调。最多 2 轮。
   - 实测：上表第二次的结果两轮校准（暖色 −0.12、高光 −5、`clarity` +0.07、橙黄单色略收、天空蓝色区域 +2；再高光 −3、橙色略收）后进入范围，局部反差保留 97.6%，局部反差仍是原片的 1.13 倍；整体去掉的只是过暖、过亮、过浓的部分。一开始用全局降饱和的做法被判为 `EXPRESSIVENESS_LOST`（局部反差掉 6%、颜色削过头）。
4. 2 轮后仍超出：交付最接近范围的一版，在回执里写明哪一项超出、为什么（例如导演单的关键效果需要更强的天空）。
5. 验收记录的“影调”“色彩”两项附上 `intensity_check` 的结论。

## 4. 不要做的

- 不要为了“落在范围中间”而把成片拉平：范围是边界，不是目标值。在范围内的成片一律不动。
- 不要因为强度检查而放弃 G 或改走更保守的路线；强度检查只做校准。
- 用户当次说了“效果再强一点”“再淡一点”，以用户为准，在回执里写明超出范围是用户要求。
- 范围只来自五张认可样本，题材有限（建筑、运河、夜景）；室内、人像以外的人文场景、风光没有专门样本，暂用 day 或 lowcolour。用户对新题材表态后再补。
