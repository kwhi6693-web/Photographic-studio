# N：按导演单调色（v0.3.0）

v0.3.0 起，N 从“只防过冲”扩展为**按导演单执行的确定性调色工具**（用户 2026-11-10 批准方案）。工具：`optional/grade.py`，只依赖 numpy 和 Pillow。

## 1. N 是什么、不是什么

- 是：对每个像素做影调和色彩的函数变换（含按区域、按色相、保边的局部明暗）。同样的输入和参数，输出逐像素相同。
- 不是：生成。不增删内容，不重画纹理，不缩放，不锐化细节，不改构图（构图用 `reframe.py`）。
- 空参数 `{}` 时输出与输入逐像素相同。

## 2. 三种用法

| 用法 | 什么时候 | 力度 |
|---|---|---|
| G 后精修 | G 的结果方向对，但导演单里有几项没做到 | 小：只补差的部分 |
| N 直出 | 宿主没有 G（T2），或 G 的候选都不合格（保底） | 中：完整执行导演单，以自然为限 |
| 防过冲 | 最后一步，成片仍有高光削波（>0.1%）时 | 用 `n_trim.py`（规则不变，见 `n_trim.md`） |

## 3. 参数（全部可选；超出范围会被截断并在回执里写明）

| 参数 | 范围 | 作用 |
|---|---|---|
| `white_balance.temp / tint` | −1…1 | 整体变暖(+)/变冷(−)；偏洋红(+)/偏绿(−) |
| `exposure_ev` | −1…1 | 整体曝光 |
| `levels.black / white` | 0…25 / 75…100 | 把这两个亮度拉到纯黑、纯白：定黑白场，去灰 |
| `shadows` / `highlights` | −25…25 | 保边地提/压暗部、亮部（单位 L*） |
| `contrast` | −0.5…0.6 | S 形曲线，端点不动 |
| `clarity` | 0…0.6 | 中等尺度的局部反差，主要作用于中间调 |
| `saturation` / `vibrance` | 0…1.6 / −0.5…0.8 | 整体饱和；自然饱和（弱色加得多） |
| `hues.<色>.sat / lum / shift` | 0…1.8 / −15…15 / −20…20° | 单独调某一类颜色（red、orange、yellow、green、cyan、blue、purple、magenta） |
| `tone_split.shadows / highlights` | 各 [a, b]，−8…8 | 暗部、亮部分别偏色（冷暖分离） |
| `regions[]` | 见下 | 局部：`lift`(−20…20)、`sat`(0.5…1.6)、`warm`(−8…8)；v0.3.7 起正向 `lift` 只落在原本亮的地方，暗背景不会被提成光圈（真要提暗处写 `lift_dark: true`，并在验收记录说明光从哪来） |
| `vignette.amount / centre / radius` | 0…10 / [x,y] 各 0.35…0.65 / 0.6…1.2 | 画面四周自然变暗；v0.3.7 起中心只能在画面中部，不会在一侧压出暗斑 |

`regions` 的形状：`rect` 或 `ellipse`（`box: [x0,y0,x1,y1]`，画面比例）、`gradient`（`from: top|bottom|left|right`，`end`）。可加 `feather`、`edge_aware: true`（沿物体边缘收住）、`only_hue`（只作用于某类颜色，例如只压蓝天）、`only_L: [lo, hi]`。

## 4. 起步幅度（经验值，来自 4 张实测，不是门槛）

G 后精修：`contrast` ≤0.10，`clarity` ≤0.15，各项提压 ≤4。N 直出：`contrast` 0.10–0.20，`clarity` 0.15–0.35，`vibrance` 0.15–0.30，`shadows` 3–8，`highlights` −3…−8，`vignette` 3–7，单色 `sat` 1.1–1.3。超过这些容易显得假。

## 5. 回执与检查

`grade.py` 输出：输入输出哈希、实际使用的参数、被截断的参数、L* 变化、色度比、削波前后、结构相关，以及标记：

- `STRUCTURE_LOW`（结构相关 < 0.90）：局部调整过猛，减小 `clarity` 和 `regions`。
- `NEW_HIGHLIGHT_CLIPPING` / `NEW_SHADOW_CLIPPING`：工具已内置防护，出现时减小幅度。
- `PARAMS_CLAMPED`：有参数超范围。

标记只提示，最终以人眼对照导演单为准。调参最多 3 轮；3 轮仍不满意就交付最好的一轮并说明。

## 6. 证据与限制

- 实测 4 张（教堂、林间蓝瓦、石壁鸽群、澳门街景）：L* 变化 −0.1…+4.0，色度 ×1.21…1.30，结构相关 0.989…0.998，均无新增削波；空参数输出与输入相同。
- N 做不到重新布光、换天空层次、去除杂物：这些只有 G 能做。N 直出的上限明显低于好的 G，它是保底和精修工具。
- 起步幅度和 0.90 的结构阈值都来自这 4 张。
