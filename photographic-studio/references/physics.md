# 自然物理原则：表现力的增强要像真的光（v0.3.6）

用户 2026-11-11：**摄影表现力的增强需要遵循自然物理原则。** 表现力是放大这张照片里本来就有的光，而不是画出一种现实中不会出现的光。本文件给出原则、给 G 和 N 的具体要求，以及检查工具。

## 1. 原则

| 原则 | 意思 | 常见违反 |
|---|---|---|
| 光有来源和方向 | 加亮的地方必须是光能照到的地方；亮度沿光的方向衰减 | 背光面比受光面还亮；凭空出现光束、光斑、补光 |
| 明暗次序不反转 | 原片里明显更亮的地方，成片里仍然更亮 | 把阴影提得比受光面亮；局部提亮造成“发光的墙” |
| 受光与阴影要分得开 | 晴天的影子是实的；阴天的光是软的 | 暗部全部提亮、高光全部压下，变成假 HDR 的“平光” |
| 色温有规律 | 日光下受光面偏暖、阴影偏冷（天空光）；人造光有它自己的颜色；同一光源照到的地方颜色一致 | 阴影比受光面还暖；整张统一染成一种暖色；夜景灯光与倒影颜色对不上 |
| 天空有渐变 | 晴天天顶深、近地平线浅；太阳一侧更亮 | 天空上浅下深；天空压得比地面还暗（逆光剪影除外） |
| 倒影比实物暗 | 水面倒影的亮度和饱和度低于实物，形状、位置与实物对应 | 倒影比实物亮或被拉长；倒影颜色与实物不同 |
| 光源最亮 | 灯、太阳、反光高光是画面最亮的东西 | 被照亮的墙比照亮它的灯还亮 |
| 空气透视 | 越远越淡、越冷、反差越低 | 远景比近景更浓更锐 |
| 边缘没有光晕 | 明暗交界是自然过渡 | 物体边缘一圈亮边或暗边（过度锐化、局部对比过强） |
| 时间与天气不变 | 光的高度、颜色要符合拍摄时刻 | 正午变黄昏、阴天变晴天 |

## 2. 给 G 的要求（写进提示词）

在“摄影意图”之后加一句：`Follow real light physics: keep the existing light direction and time of day, shadows stay darker and cooler than sunlit areas, sky graded naturally, reflections dimmer than the objects, no added light sources, no halos. Do not add a spotlight or a glow around the subject; dark backgrounds stay as dark and clean as in the source.`（v0.3.6；第二句 v0.3.7 加，`g_prompt_template.md` 引用此句。）

## 3. 给 N 的要求（`grade.py` 参数怎么用）

- **v0.3.7 不造光**：突出主角优先收周边；`grade.py` 的正向 `lift` 会自动按每个像素原本的亮度起作用（暗处几乎不动），所以不会在暗背景上提出光圈；`look_transfer.py` 不会把 G 在暗背景上加的光带过来。
- 提亮主角用 `regions`，范围要跟着光走：只在受光的区域提亮（可加 `only_L` 只作用于本来较亮的部分），不要把阴影里的东西提得比受光面亮。
- 提暗部（`shadows`）要有限度：提完之后影子仍然明显比受光面暗。
- 冷暖：`tone_split` 亮部偏暖、暗部偏冷，方向与日光规律一致；反过来只在原片本来就如此时（如室内暖灯）。
- 天空：用 `gradient` 从上往下压，越往地平线压得越少。
- `clarity` 适量，出现边缘亮边、暗边就减小。

## 4. 检查（验收第七项“自然度”的一部分，必做）

运行 `optional/physics_check.py 原片 成片`，它检查八项：明暗次序、受光与阴影的分离、阴影冷暖、天空渐变、边缘光晕、光源最亮，以及 v0.3.7 新增的**假聚光**（暗背景上出现没有光源的光圈、椭圆亮区）和**暗斑**（局部压出的一块暗、偏到一侧的暗角）。

- `PHYSICALLY_PLAUSIBLE` → 通过。
- `CHECK_BY_EYE: <项目>` → 在 100% 下看那一项指出的问题。确实违反物理 → 用 `grade.py` 修（参照第 3 节）或回到上一步；修完再查。确认是原片本身如此（例如逆光剪影、室内暖灯造成阴影更暖）→ 在验收记录里写明原因后可以交付。
- 验收记录第七项写成：`自然度 ✓（100% 看了…；physics_check 通过）`。

## 5. 证据与限制

- 人为制造的五种违反里，工具抓到四种：假 HDR 平光、明暗反转（局部把暗处提得比亮处亮）、边缘光晕、天空渐变反转；第五种（阴影变暖但没有暖过受光面）不算违反，未报告。
- 用户认可或接受的 13 张成片（WO-8 建筑、运河、夜景，祭堂 v0.3.4，夜景 v0.3.4，威尼斯人，木构老街，教堂、鸽群、街景、林间蓝瓦 N 直出，以及 v0.3.5 祭堂校准后）全部通过；用户没选的祭堂 v0.3.5 被报告明暗次序有 4% 的反转（阴影里的石面被提得比部分受光面亮），与“不自然”的观感一致。
- v0.3.7：用户发来的三张博物馆成片（蓝釉瓶、铜牛灯、青瓷罐）三张都被新检查抓到（假聚光、暗斑）；7 组回归样本的默认路线成片全部不报这两项。阈值是在这十张上定的，样本少，可能误报或漏报。
- v0.3.8：**光照到表面会让表面的纹样一起变亮变清楚，光晕只是加一层雾**。所以深色主体的暗面被提亮、纹样随之显现，是受光，不是假光晕；工具按这一点区分。**G 删掉原片的光也同样违反“光有来源”**：局部比整体趋势暗 8 以上、而原片那里有光的，不带进成片。
- 工具看的是整体统计，不认识物体：认不出倒影亮过实物、凭空加的光源、人造光颜色不一致等，这几条仍要靠眼睛。
