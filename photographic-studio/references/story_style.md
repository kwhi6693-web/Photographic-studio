# 读片：故事与风格（v0.2.2）

用户 2026-11-10 明确：本项目要**有审美地处理照片，让原片的故事感和风格通过整条链路表现出来**。本文件是 A 阶段的核心，决定 G 的提示词、构图取舍、贴回后的复核和交付说明。

## 1. 先读出这张照片在讲什么

动手之前，用两三句话写下：

- **故事**：拍的是什么时刻、什么处境、什么关系。例如“午后老街，阳光斜照，路人各走各的，安静而有生活气”“雨后的港口，冷清，灯刚亮”“古墙前一群鸽子，时间感和肃穆”。
- **情绪**：这张照片应该让人感到什么（温暖、宁静、庄严、热闹、怀旧、清冷、神秘……），只选一到两个。
- **主角**：画面里最该被看见的是什么（一面墙、一束光、一个人、一块招牌、一片天空），其余都为它服务。

故事必须**从这张原片里读出来**：光线方向、时间、天气、色调、人的动作、物件的状态。不得套用与画面无关的故事，不得改变照片的时间或天气（不把阴天变晴天、白天变黄昏）。

## 2. 再定风格方向

根据故事和原片自身的光色，选一个风格方向，用一句话写清。下面只是常见方向，不是预设滤镜；可以组合，也可以另起：

| 方向 | 适合 | 光与色的手段 |
|---|---|---|
| 暖光纪实 | 午后街景、老城、生活场景 | 保留斜射暖光和长影，暗部微暖，色彩饱满但不艳 |
| 清透建筑 | 晴天立面、现代建筑、几何结构 | 天空干净有层次，墙面明亮通透，线条和材质清楚，冷暖分明 |
| 低调夜色 | 夜景、室内弱光 | 保住黑，突出光源和被照亮的部分，控制溢光，色温有冷暖对比 |
| 静谧风景 | 园林、山林、水面、雾 | 柔和过渡，空气感，前中后景分层，不过度锐化 |
| 浓郁街头 | 招牌多、色块多、人多的场景 | 色彩更鲜明，局部反差加强，节奏感 |
| 肃穆古迹 | 古墙、碑、庙宇、教堂 | 压住高光，石材厚重，光影立体，色彩沉稳 |

风格方向要**放大原片已有的气质**，而不是换一种气质。

## 3. 让整条链路服务于故事和风格

| 环节 | 怎么用 |
|---|---|
| G 提示词 | “摄影意图”一行写成风格方向的具体光色手段，并点出主角（见 `g_prompt_template.md` 第 2 节） |
| 构图优化 | 只在能让主角更突出、故事更清楚时裁切或拉直；裁掉分散注意力的边缘，保留讲故事所需的环境 |
| 细节贴回 | 贴回不改变风格：贴回区域取 G 的局部光色，复核时看贴回处是否和整体气质一致 |
| N | 只收过冲，不改风格 |
| 复核 | 第一问：**成片有没有把写下的故事和风格表达出来？** 没有，就按强度不足或方向不对处理（可重跑一次 G） |

## 4. 交付时说什么

成片下第一行写：`故事：……｜风格：……`（各一句）。然后才是结果标签和简短回执。用户对成片的接受与否，连同这一行一起记入累计标记表，供日后学习用户偏好的风格。

## 5. 边界

- 审美判断来自执行者和图像模型，本文件只给出结构，不能保证每张都打动用户；用户的接受与否是唯一评判。
- 风格不得以牺牲人眼可见的关键事实为代价（总则不变）。
- 用户当次指定了风格（例如“要胶片感”“冷一点”），以用户为准。
