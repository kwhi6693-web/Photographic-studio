# 读片：看点与风格（v1.0.9）

本项目要**有审美地处理照片**，让原片最值得看的东西通过整条链路表现出来。本文件决定导演单第一行，以及 G 的提示词、参数取舍、构图重构和验收的方向。

v1.0.9（用户 2026-11-14）：**叙事只是其中一种**。不是每张照片都在讲故事：有的好看在线条和秩序，有的在光本身，有的在颜色，有的在质感，有的在气氛。先判断这张照片的看点是什么，再定风格。

## 1. 先读出这张照片的看点

动手之前，用一两句话写下：

- **看点**：这张照片为什么值得看。从下面选一个主看点，最多再加一个次看点；也可以另起：

| 看点 | 是什么 | 例子 |
|---|---|---|
| 叙事 | 一个时刻、一种处境、一段关系 | 午后老街路人各走各的；雨后港口灯刚亮 |
| 几何与秩序 | 线条、对称、重复、透视、图形 | 骑楼立面的连续窗格；天窗下交错的投影 |
| 光影 | 光本身：斜射的光、光斑、明暗交界、剪影 | 窗光落在书架上；逆光的桥洞 |
| 色彩 | 色块之间的关系、互补色、一种主色 | 灰砖前的一树红枫；蓝天下的黄墙 |
| 质感与细节 | 材质、纹理、工艺 | 石壁的风化；铜器的错金银 |
| 氛围与情绪 | 空气、天气、温度感 | 晨雾里的园林；暗厅里的灯笼 |
| 空间与尺度 | 纵深、层次、大与小 | 长街透视；山前的一座小亭 |
| 极简 | 大面积留白中的一个元素 | 白墙上的一枝影子 |

- **主角**：画面里最该被看见的是什么（一面墙、一束光、一组线条、一块颜色、一片天空），其余都为它服务。
- **情绪**（可选）：这张照片应该让人感到什么，只选一到两个。

看点必须**从这张原片里读出来**：光线方向、时间、天气、色调、线条、物件的状态。不得套用与画面无关的看点，不得改变照片的时间或天气（不把阴天变晴天、白天变黄昏）。

## 2. 再定风格方向

根据看点和原片自身的光色，选一个风格方向，用一句话写清。下面只是常见方向，不是预设滤镜；可以组合，也可以另起：

| 方向 | 适合 | 光与色的手段 |
|---|---|---|
| 暖光纪实 | 午后街景、老城、生活场景 | 保留斜射暖光和长影，暗部微暖，色彩饱满但不艳 |
| 清透建筑 | 晴天立面、现代建筑、几何结构 | 天空干净有层次，墙面明亮通透，线条和材质清楚，冷暖分明 |
| 极简几何 | 线条、图形、重复、留白 | 色块干净、反差明确，去掉杂色，留白平整 |
| 光影戏剧 | 斜光、光斑、剪影、明暗交界 | 压住暗部、守住高光，让光的形状清楚；不另造光 |
| 色彩构成 | 主色突出、互补色、色块关系 | 主色加强、次要色收敛，冷暖关系清楚 |
| 低调夜色 | 夜景、室内弱光 | 保住黑，突出光源和被照亮的部分，控制溢光，色温有冷暖对比 |
| 静谧风景 | 园林、山林、水面、雾 | 柔和过渡，空气感，前中后景分层，不过度锐化 |
| 浓郁街头 | 招牌多、色块多、人多的场景 | 色彩更鲜明，局部反差加强，节奏感 |
| 肃穆古迹 | 古墙、碑、庙宇、教堂 | 压住高光，石材厚重，光影立体，色彩沉稳 |
| 质感特写 | 材质、工艺、细节 | 局部反差带出纹理，色彩准确，不磨平也不过锐 |

风格方向要**放大原片已有的气质**，而不是换一种气质。

## 3. 让整条链路服务于看点和风格

| 环节 | 怎么用 |
|---|---|
| G 提示词 | “摄影意图”一行写成风格方向的具体光色手段，并点出主角（见 `g_prompt_template.md` 第 2 节） |
| N 参数 | 诊断出的问题里，先修妨碍看点的那些（例如几何看点先修倾斜和杂色，光影看点先修发灰和溢光） |
| 构图重构 | 按看点选手法（`reframe_rules.md` 第 2 节）：叙事保留讲故事的环境，几何对齐线条和对称，光影把框落在光上，极简留出平整的空白 |
| 细节贴回 | 贴回不改变风格：贴回区域取 G 的局部光色，复核时看贴回处是否和整体气质一致 |
| 验收 | 第一问：**成片有没有把写下的看点和风格表达出来？** 没有，就按方向不对或力度不够处理（可重跑一次 G） |

## 4. 交付时说什么

成片下第一行写：`看点：……｜风格：……`（各一句）。然后才是结果标签和简短回执。

## 5. 边界

- 审美判断来自执行者和图像模型，本文件只给出结构，不能保证每张都打动用户；用户的接受与否是唯一评判。
- 风格不得以牺牲人眼可见的关键事实为代价（总则不变）。
- 用户当次指定了风格（例如“要胶片感”“冷一点”），以用户为准，只用于这一张。
