# 能力分级（v1.6.2）

本 Skill 面向任何能看图的大模型 agent。宿主的工具各不相同，规则只保证同一套“读片 → 出片 → 检查 → 交付”的流程，并按宿主实际具备的能力降级执行、如实标注。

## 1. 开工自检

运行 `python3 optional/selfcheck.py`（**不要加 `-I`**：它会藏掉装在用户目录里的 OpenCV）。不能运行代码就跳过，直接按下表判断。它报告 numpy、Pillow、OpenCV 是否可用、包里每个工具能不能跑，并给出建议级别。没有 OpenCV 也能完整走主线（`cvlite.py` 用 numpy + Pillow 代替，结果相同），不要为此安装任何包。再由 agent 自己确认：能否看图；有没有**以原片为输入**的图像编辑工具（记作 G）。

## 2. 四个级别

| 级别 | 宿主具备 | 走法 | 成片标签 |
|---|---|---|---|
| T1 完整 | 看图 + G + 代码（numpy、Pillow；有没有 OpenCV 都可以） | 读片 → keep 核对 → G → `pipeline.py --g-direct` → 交付 | `G 直出 + 细节贴回`；极暗原片、大面积 keep 或 G 直出失败时 `原片像素 + G 光色`；连它也做不成时 `N 直出` |
| T2 调色 | 看图 + 代码，没有 G | 读片 → `pipeline.py 原片 原片 参数.json 成片.png --quick-n` → 交付 | `N 直出` |
| T3 生成 | 看图 + G，不能运行代码 | 读片 → G → 人眼对照原片复核 → 交付；没有对齐、贴回和哨兵，写明“未做确定性检查” | `G（未检查）` |
| T4 顾问 | 只能看图 | 只输出读片结果和可照着做的调整建议 | 无成片 |

- 级别写进回执。不得用低级别的结果冒充高级别（例如把 N 直出标成 G）。

## 3. 宿主无关的要求

- G 指“宿主自带的、能以当次原片为输入的图像编辑工具”，不限定厂商。输出尺寸以实际为准，写进回执。
- 原片必须是当次用户提供的那一张；能否证明工具内部真的读取了原片，取决于宿主，证明不了就写“无法确认”。
- 照片的编辑授权按宿主分别计算：用户在一个 agent 里的授权不延伸到另一个。
- 任何宿主都可用“附件模式”：把规则包发给 agent，核对 `SHA256SUMS.txt` 后执行。

## 4. 证据

T1 实测过：ChatGPT iOS App（无 OpenCV，走 cvlite）、Gemini。T2 在维护者环境跑通。T3、T4 没有实测。其他宿主没有证据。
